# 短波形 smoke 的读法

`tb_tpu_top_smoke.sv` 只运行一个 INT8、4×4 的真实 TOP 任务。顶层例化名是 `dut`，36 个外部端口全部显式声明。`phase` 依次表示复位、配置、权重加载、START、输入、等待完成、报告读取、W1C 和结束。日志输出每个阶段和关键握手的时间，便于在 Verdi 直接缩放。

测试通过真实 AHB 写 H/W=3（表示实际4）、模式=1（INT8）、EN 和 CRG_EN。每行只写4个有效权重列，再写 LOCK；每次 LOCK 后等待200ns，遵循软件接口约束。矩阵为 `A[k,r]=(k+1)*(r+1)`、`B[r,c]=r+c+1`，因此独立数学结果 `C[k,c]=(k+1)*(30+10*c)`。输入4拍，每拍低4个32bit lane有效，其余补0。

输出按列错开，不是每拍输出完整的一行矩阵。下面的数字按 lane0、lane1、lane2、lane3 排列；lane0 是 `wr_tdata[31:0]`。

| 输出拍 | lane0 | lane1 | lane2 | lane3 | LAST |
|---|---:|---:|---:|---:|---:|
|0|30|0|0|0|0|
|1|60|40|0|0|0|
|2|90|80|50|0|0|
|3|120|120|100|60|0|
|4|0|160|150|120|0|
|5|0|0|200|180|0|
|6|0|0|0|240|1|

先看 `rd_tvalid&&rd_tready` 的4次接收及最后一次 `rd_tlast`，再看 `wr_tvalid&&wr_tready` 的7次发送和唯一 `wr_tlast`。输出有效字节掩码恒为全1，INT8 输出的 `wr_tuser=0`；DFT、ID、DEST 等控制保持固定值是正常的有效配置。

随后 CPU 轮询字节地址0x410（DONE）。DONE 出现时，报告已完整发布，输入计数=4、输出握手计数=7、活动规模=0x00040004、错误计数=0。测试再次读取 DONE，确认它保持为1；最后写同一 DONE 地址 bit0=1，读回0，并确认先前报告数值仍保留。测试检查的是所有512bit数据、字节掩码、边带、LAST、计数和软件读回，不只是生成波形。

VCS 编译定义 `FSDB_TRACE`，运行传入 `+FSDB_FILE=waves/tpu_top_smoke.fsdb`，记录测试顶层及其完整 DUT 层次。也可定义 `VCD_TRACE` 并传入 `+VCD_FILE=...`。正常结束标记是 `TPU_TOP_SMOKE_PASS`；任何检查失败会产生 fatal。此短测试用于讲解；完整48任务回归保留在原 `tb_tpu_top.sv` 中。
