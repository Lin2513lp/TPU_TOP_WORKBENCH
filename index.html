TPU_TOP Design Workbench

Top-level integration of a 16 × 16 multi-precision TPU, connecting AHB configuration, clock/reset control, AXI streams, dataflow control and the systolic array. The workbench runs in a browser and requires no installation.

Open the TPU_TOP Workbench

Workbench contents

  • System architecture and the complete connectivity diagram for seven top-level module instances.
  • 36 external ports, 32 register addresses, source browsing and downloads.
  • 4 × 4 INT8 smoke waveforms, a detailed timeline and hexadecimal stimulus, expected results and actual outputs.
  • AHB configuration, weight loading, START, stream handshakes, report reads and DONE write-one-to-clear.

Source files

The repository includes 32 project files: the integrated TOP, its compiled RTL dependencies, smoke testbench, Makefile, CDC constraints and integration notes. The workbench code viewer uses the same snapshot.

SA keeps its original 18 ports; existing CTRL VALID/LAST carry vector markers. The unchanged strict TOP smoke now passes 107 checks in Questa and VM VCS. Current native Verdi evidence and source hashes are included.
